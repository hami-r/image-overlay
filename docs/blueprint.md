# **App Name**: Image Overlay Studio

## Core Features:

- Text Input: Allow users to input custom text to overlay on images.
- Background Selection: Provide options to select a solid background color for the image. Choose color from existing nice looking background patterns. This tool reasons whether background images are already opaque, and will either apply text directly or wrap in an opaque rectangle before overlaying.
- Image Upload: Enable users to upload their own images as a background.
- Preview & Download: Allow users to preview the final image and download it in a common image format (.jpg, .png).
- Text Case Options: Provide options to convert the input text to title case, pascal case, uppercase, and lowercase.
- Font Family Selection: Allow users to choose from a variety of font families for the text overlay.
- Mobile Responsiveness: Ensure the application is fully responsive and adapts to different screen sizes.
- Text Alignment Options: Allow users to choose the alignment of the text overlay (left, center, right).
- Batch Image Creation (Developers Only): Allow developers to input a JSON array to create multiple images at once.

## Style Guidelines:

- Primary color: Soft lavender (#E6E6FA) for a calm and gentle feel.
- Background color: Light gray (#F0F0F0) to maintain a minimalist design.
- Accent color: Pastel green (#C1E1C1) for subtle highlights and call-to-action elements.
- Body and headline font: 'Inter' (sans-serif) for a clean and modern appearance.
- Use simple, outline-style icons for a minimalist aesthetic.
- Maintain a clean, spacious layout with ample whitespace.
- Use subtle transitions and animations to provide gentle feedback to user interactions.
